跨裝置同步

用你自己的 GitHub 私密 Gist 當雲端：iPhone、iPad、電腦填同一組 Token 與 Gist ID，打開 App 時會自動抓最新資料、存檔時自動上傳。多台裝置各自新增的紀錄會自動合併。

「同步連結」含你的 Token，只傳給自己的另一台裝置（AirDrop／訊息給自己），不要分享給別人。

第一次設定怎麼做？
  1. GitHub → 右上頭像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)，只勾選 gist，產生後複製 ghp_… 開頭的 Token。
  2. 開啟 gist.github.com，檔名填 meta.json、內容填 {}，按 Create secret gist。
  3. 複製網址最後那串 32 碼（或整段網址），連同 Token 貼到上面，按「儲存並同步」。
  4. 其他裝置：按「複製同步連結」傳過去開啟，或手動貼同一組 Token 與 Gist ID。
