計算規則

☁️ 跨裝置同步（GitHub 私密 Gist，與牙科申報記帳 App 相同做法）

iPhone、iPad、電腦填同一組 Token 與 Gist ID；打開時自動抓最新資料，修改後自動上傳。可以直接用申報記帳 App 那一個 Gist，本 App 只會讀寫其中的 pgy-schedule.json，不會動到申報資料。兩台裝置改了不同日期會自動合併，同一格以較晚修改的為準。

偵測到這台裝置已設定「牙科申報記帳」的同步。
第一次設定步驟
  1. GitHub → 頭像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token，只勾 gist。
  2. 到 gist.github.com 建一個 secret gist（檔名 pgy-schedule.json、內容 {}），或直接沿用申報記帳 App 的 Gist。
  3. 在這裡貼上 Token 與 Gist ID，按「儲存並同步」。
  4. 其他裝置：按「複製同步連結」傳過去打開即可（申報記帳 App 產生的同步連結這裡也能用）。
